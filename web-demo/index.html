03 / THE METHOD

Appearance and motion.
Modeled together.

An independent interaction control layer. Dual RGB–Pose tokens and a system-state token predict the next event at 1-second intervals.

01

RGB pathway

Fine-grained appearance, facial expressions, and gaze.

SigLIP Vision Encoder
Visual Resampler
RGB tokens
02

Pose pathway

Temporal motion of hands, face, and other keypoints.

RTMPose + ST-GCN Encoder
Temporal Adapter + Projector
Pose tokens
03

Interaction prediction

Visual tokens combined with the current system state.

Qwen3-0.6B · LoRA
Unified interaction head
Five event classes
Input accumulates from the latest system-state transition. Perception continues during response generation.
REJECT

Non-signing movement or a brief backchannel that needs no system response.

INCOMPLETE

A valid signed utterance is still in progress.

WAIT

A brief pause, deceleration, or posture hold within an unfinished utterance.

COMPLETE

The current utterance is finished. Begin the downstream response.

BARGE

A new valid utterance begins during system output. Stop the output.
