# SignDuplex interactive website

Published at [SignDuplex](https://signduplex-demo.brown-charm-3727.chatgpt.site/#demo).

This directory mirrors the public static website. It contains ten selectable How2Sign clips and three recorded model walkthroughs, together with institution branding, research figures, and the live DEMO_v5.1 interface. The model runs on a separate inference service; hosting these static files alone does not run inference.

## Preview

```sh
python -m http.server 8791 --directory web-demo
```

Open `http://localhost:8791`. No build step or package installation is needed.

## Live inference

`demo-config.js` sets the HTTPS API origin. The current endpoint uses a temporary Cloudflare tunnel and requires the demo server and tunnel to remain running. Restarting the tunnel can change its hostname; update this setting and republish the website when that happens. The recorded examples remain available independently of the inference service.

The frontend creates an anonymous session, uploads a chosen video, starts an analysis, and polls only that run until it completes. The service must support session-scoped `/api/upload` and `/api/runs` endpoints and permit this website's origin through CORS. No server credentials belong in the static bundle.

Predictions are computed before playback. Each decision uses only frames available up to its video timestamp. The interface then synchronizes those predictions with the video clock, including seeking and playback-speed changes. System response activity is simulated; no translation or speech is generated by this interface. Reference text is a source annotation.

## Public examples

`samples.json` lists the ten clips in `media/`. Three entries marked `featured` appear in the walkthrough gallery. Their records in `recordings/` come from saved model runs; using **Analyze video** starts fresh inference. The interruption example starts in a controlled RESPONDING state.
